学习路线：五个递进任务

讲义里的核心经验是“任何复杂桥梁，不过就是点和线的连接”。课堂中把这句话拆成五个任务，学生每一步都有可见产物。

1一座拱桥

从自然语言描述出发，生成可旋转 HTML 模型。

2不同尺寸

把跨度、拱高、横梁间距变成滑块和批量变体。

3泛化提示词

从具体桥变成桥型生成契约：组成、坐标、连接、输出。

4桥型迁移

用同一套结构思路覆盖斜拉桥、悬索桥。

5工程导出

导出 FEM 节点/单元和 OBJ，进入计算、PPT、电子教材。

任务一：先做一座“说得清”的拱桥

第一次不要追求漂亮，先追求结构关系不乱。学生要能指出主梁、横梁、拱肋、吊杆在哪里，谁连接谁。

课堂操作

  • 输入“请生成提篮拱桥 HTML 三维模型”。
  • 观察错误：吊杆是否悬空，拱肋是否穿过主梁，坐标是否混乱。
  • 记录 AI 犯错原因：结构组成、连接关系、坐标约束缺失。

学生产物

  • 一份初版 HTML 模型。
  • 一张“问题截图 + 错误说明”。
  • 一段改进提示词，至少补充组成、连接、坐标三类约束。

任务二：让拱桥从“一个结果”变成“参数对象”

这一步是身份转换的关键：学生不再只是拿到一个模型，而是开始控制模型生成逻辑。

尺寸变体要求

在现有提篮拱桥模型中加入参数化控制：
- 跨度 L：30m 到 100m
- 拱高 H：8m 到 30m
- 横梁间距 S：2m 到 10m
- 滑块变化后实时重建模型
- 标签同步显示当前参数
- 保持 x=桥向，y=横桥向，z=高度

观察重点

  • 跨度变化后，横梁数量是否自动改变。
  • 拱高变化后，吊杆长度是否跟随更新。
  • 间距变化后，节点和单元导出是否同步。
不要只看模型是否“像桥”，还要看参数变化后结构关系是否保持一致。

任务三：把具体提示词泛化成“桥梁生成契约”

泛化提示词不是写得更长，而是把每次都容易遗漏的约束固定下来，让学生知道以后换桥型也照这个框架说清楚。

泛化提示词骨架

请生成【桥型】HTML 三维模型。

1. 坐标约定：
   x=桥向，y=横桥向，z=高度。

2. 结构组成：
   列出主承重构件、次要构件、桥面/主梁、连接件。

3. 几何控制：
   给出关键点、跨度、高度、间距、宽度、构件截面。

4. 连接关系：
   明确谁连接谁，连接发生在哪些 x/y/z 位置。

5. 参数化：
   至少提供跨度、主高度、构件间距三个滑块。

6. 输出契约：
   - 可旋转 HTML
   - FEM 节点坐标和单元信息
   - OBJ 导出
   - 中文 UI
   - 不使用未解释的硬编码尺寸

泛化训练

  • 把“提篮拱桥”替换成“斜拉桥”，学生补充塔、斜拉索、锚点。
  • 把“提篮拱桥”替换成“悬索桥”，学生补充主缆、吊索、索塔、锚碇。
  • 每组提交一份桥型专用提示词和一份错误复盘。

任务四：从拱桥迁移到斜拉桥、悬索桥

迁移时讲清楚“相同的框架”和“不同的受力构件”。学生会发现 AI 能生成很多东西，但工程常识要靠提示词和验收清单托住。

拱桥

主拱承担主要受力，吊杆把横梁/主梁连接到拱肋。关键是拱轴线、吊杆竖向连接、横梁间距。

斜拉桥

索塔与斜拉索控制桥面。关键是塔高、索面、锚点排序，避免拉索交叉或悬空。

悬索桥

主缆、吊索、索塔和锚碇构成体系。关键是主缆垂度、吊索间距、桥面锚点。

任务五：进入 FEM、OBJ 与后续工程表达

这一步把“能看”推进到“能用”：FEM 需要节点和单元，PPT/电子教材需要 OBJ，3D 打印还需要实体厚度和可制造性。

FEM 输出

  • 节点：ID、X、Y、Z、构件标签。
  • 单元：ID、类型、节点 i、节点 j、组别。
  • 要求节点去重，避免同一连接点重复编号。

OBJ 输出

  • 用于 PPT 平滑过渡、电子教材旋转展示、模型检查。
  • 坐标使用桥梁模型坐标，不要导出 Three.js 映射坐标。
  • 导出后用 OBJ 查看器检查是否缺构件。

DeepSeek 不能“复刻 skill”，那应该怎么讲？

建议讲成“搭建一个桥梁建模 Agent”。DeepSeek 是生成模型，Agent 是组织工作流的执行者，Skill 是这个 Agent 的说明书和工具箱。

模型

DeepSeek V4 Flash 负责根据提示词生成文字和代码。

代理运行时

本地 Node 代理或云函数负责保管 API Key、限流、保存结果。

工具

Three.js、OBJ 查看器、FEM 导出脚本负责把生成结果变成可检查产物。

Skill

把桥型公式、坐标约定、验收清单写成可复用工作说明。

讲授重点：不要说“DeepSeek 学会了这个 skill”，而要说“我们用 Agent 外壳把 DeepSeek 的一次性生成，变成可重复、可检查、可扩展的任务流程”。

实时实验室：学生现场生成与预览

课堂上推荐使用“教师限额代理”或“学生本地代理”，不要把共享 API Key 写进前端页面。

书中 OBJ 展示：旋转、放大、检查模型

电子教材里可以直接嵌入 OBJ 查看器。学生导出 OBJ 后，既能放进 PPT，也能在书中旋转查看，形成“生成结果即教材素材”的闭环。

学生提交与验收清单

每组最后不只交一个模型，而是交“生成过程 + 提示词 + 可运行代码 + 工程导出 + 复盘”。

一座基础拱桥构件完整，坐标方向正确，能旋转查看。
三个尺寸变体跨度、拱高、间距变化后结构关系不崩。
一份泛化提示词能迁移到斜拉桥或悬索桥。
FEM 节点/单元导出节点去重，单元分组清晰。
OBJ 展示导出 OBJ 并在查看器中旋转、缩放、检查。
Skill 草案把桥型约束、生成步骤、验收标准写成 Agent 可复用说明。
