# DeepSeek v4pro 提篮拱桥生成提示词

请给我生成一个提篮拱桥 HTML 三维模型。

- **目的**：我想建造一座拱桥，提篮拱桥。
- **组成**：包括主梁、主拱、吊杆、横梁。
  - 传力方式：主梁架在横梁上，横梁左右两端通过吊杆分别拉在左右侧拱肋上。
  - 主梁：从（0，0，0）到（50，0，0）；主梁在 y 方向宽 10m，在 z 方向高 1m。
  - 横梁：横梁跨度为 10m，在主梁下方 1m，横梁间距 5m。
  - 拱：两个拱肋形状均为抛物线，起始点、中点、终点分别为（0，±6，0）；（25，±1，15）；（50，±6，0）。由拱上的三个点确定拱的轴线。
  - 坐标轴：z 为高度，x 为桥向。
- **连接**：拱肋对应 x 位置连接在对应主梁相应横梁一侧。
- **要求**：请帮我制作一个三维可旋转模型。
- **输出**：html 格式模型代码。
- **额外要求**
  - 参数化按钮/拖动条调整结构尺寸（跨度、拱高度、横梁的间距）
  - 额外增加按钮，输出节点坐标和单元信息，目的是对接后续的有限元计算
  - 可以导出这个模型的 OBJ 模型吗
